# Code of conduct

Be decent to people. Assume the person you are replying to is acting in good
faith and knows something you do not.

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Harassment, personal attacks, and demeaning comments are not
welcome, and neither is derailing a technical thread into a personal one.

Report a problem to sakhi_mansoor@yahoo.com. Reports stay private.
